# SEIR_model 
SEIR Model (NetLogo)

An agent-based simulation of the SEIR epidemic model built using NetLogo.

• Model Abbreviations
S (Susceptible): Healthy individuals who can contract the disease.
E (Exposed): Infected individuals in incubation (not yet contagious).
I (Infectious): Sick individuals able to transmit the virus.
R (Recovered): Individuals who recovered and gained immunity.

• How to Run
Open SEIR_Model.nlogo in NetLogo.
Click setup to initialize the population.
Click go to run the simulation and observe the plot evolution.

• Parameters
Tweak transmission rates, contact frequency, and incubation periods using the interface sliders to see how the outbreak curve changes.
